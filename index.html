Data Backup & Restore (Tiiny.host Ready)

Your data is safely stored in LocalStorage and synced with Firebase. We recommend downloading regular JSON / PDF backups for your records.

1. Full Data Backup (PDF Document)

Download a complete printable PDF statement of all 8 rooms, tenants, electricity bills and payment history.

2. Full Data Backup (JSON File)

Export a full JSON database file for device transfers, offline storage and quick restoration.

3. Restore Data (Upload JSON Backup)

Select a previously downloaded .json backup file to restore all your records instantly.

4. Load Sample / Real Data

Populate Rooms 1 to 8 with real statements and sample payment records.

5. Clear / Empty Room Data

Rooms 1 to 8 will remain permanently intact. Only occupants, payments and meter readings will be cleared.

6. Reset / Clear All Data

Clear all tenant records and reset all rooms to fresh vacant state (0 readings).

How to Deploy Live on Tiiny.host?
  1. Download or create a .zip file of this project folder.
  2. Visit https://tiiny.host/ in your browser.
  3. Drag & drop the zip file, enter your site name and click "Publish"!
  4. Your Room Rent Management website will be live instantly worldwide.
